# Third-party payload policy

Identity redaction is enforced by `@kkd/pii` before these payloads leave KKD. Raw clinic transcripts are never written to logs.

| Provider             | Fields sent                                                                                                | Why necessary                                                           | PII redacted                                                                                                                     | Raw health content                              | Retention                                   | Deletion                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------- | --------------------------------------- |
| Claude (`@kkd/ai`)   | Sanitized patient text, locale, missing field ids, already-collected fact ids, session facts for summaries | Symptom extraction, question planning, language handling, summarization | Yes, policy `ai`. Fail closed if redaction fails.                                                                                | Yes, after redaction. Measurements kept.        | Anthropic API retention per their agreement | Do not send reversible placeholder maps |
| Presidio Analyzer    | Original text for `/analyze` only, on KKD-controlled infrastructure                                        | NER for names/addresses                                                 | Analyzer sees text in order to detect PII. It is not a product LLM.                                                              | Yes, locally/sidecar                            | No KKD persistence of analyzer input        | Sidecar is ephemeral                    |
| ElevenLabs           | Voice audio / approved transcript fields                                                                   | Voice channel                                                           | Yes, policy `webhook` / `ai` as wired by voice workstream                                                                        | Transcript only when the voice task requires it | Provider retention per agreement            | Session close deletes KKD copies        |
| WhatsApp provider    | Message text, destination identifiers required by the API                                                  | Channel delivery                                                        | Message bodies sanitized with `webhook` before any copy is forwarded to other processors. Provider already has the MSISDN.       | Symptom text as typed by the user on WhatsApp   | Provider retention                          | KKD ephemeral session TTL               |
| USSD provider        | Short prompt/response strings, MSISDN                                                                      | Channel delivery                                                        | Same as WhatsApp: `webhook` for forwarded copies                                                                                 | Constrained USSD text                           | Provider retention                          | KKD ephemeral session TTL               |
| Geolocation provider | Search query / coarse area, never a name or phone                                                          | Care routing                                                            | Coordinates sanitized unless the request _is_ a live location search. Anonymous clinic mode keeps precise coordinates ephemeral. | No symptom transcript                           | Cache with `source` + TTL                   | Purge with session                      |

Logging/Sentry: request and response bodies disabled. Only safe metadata (`SAFE_EVENT_KEYS` in `@kkd/observability`). Residual strings pass policy `log`.
